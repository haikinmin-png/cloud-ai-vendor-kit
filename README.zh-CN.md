# cloud-ai-vendor-kit

**每个 AI 应用都要重写一遍的脏活累活——一次写好、测好、共享出来。**

[English](README.md)

用国内云厂商的 AI API 做应用（换脸、照片跳舞、风格化……），每次都要重写四件事：

1. **请求签名**——腾讯云 TC3-HMAC-SHA256，细节错一点就全盘报错
2. **异步任务轮询**——跳舞/视频任务要跑几分钟，需要退避、超时和失败处理，而不是一个 setInterval 祈祷
3. **配额护栏**——每次调用都花钱，一个失控循环或一个滥用用户几分钟就能烧掉一天预算
4. **Mock 适配器**——在 API 合同、密钥、厂商入驻都还没到位之前，先把产品做出来、演示出来

本库就是这四件，零依赖；适配器接口保持稳定，换厂商（或多厂商并行）不用重写产品。

## 用法

见英文 README 的代码示例：签名客户端、任务轮询、配额护栏、Mock 适配器四段。

## 设计原则

- **密钥永不进代码**：只从环境变量读，库不记录、不落盘
- **适配器接口就是产品边界**：同步 `faceswap`/`stylize`、异步 `animateSubmit`+`taskGet`，真实厂商按同一形状实现
- **成本是一等公民**：按次计费下，配额和轮询超时是产品决策，不是运维细节
